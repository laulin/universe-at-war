# Plans d'implémentation

Les plans détaillent, tâche par tâche, l'implémentation des jalons restants sur
le socle des Milestones 0 à 2. Chaque tâche est une tranche TDD close par un
commit ; l'arbre reste compilable et les tests verts à chaque étape.

| Fichier | Contenu |
| --- | --- |
| [`2026-09-05-roadmap-m3-m10.md`](2026-09-05-roadmap-m3-m10.md) | écarts spécification/code, décisions transverses, feuille de route et dépendances |
| [`2026-09-05-partie-0-socle.md`](2026-09-05-partie-0-socle.md) | socle transverse : dispatch d'événements, ruleset évolutif, multi-planètes, layout, inscription, journalisation |
| [`2026-09-05-milestone-03.md`](2026-09-05-milestone-03.md) | recherches, chantier spatial et défenses |
| [`2026-09-05-milestone-04.md`](2026-09-05-milestone-04.md) | moteur de flotte |
| [`2026-09-05-milestone-05.md`](2026-09-05-milestone-05.md) | espionnage, combat et débris |
| [`2026-09-05-verification.md`](2026-09-05-verification.md) | vérification de bout en bout et scénarios prouvés |

Les Milestones 6 à 10 sont cadrés dans la feuille de route ; leur plan détaillé
sera écrit au démarrage de chaque jalon, une fois les interfaces des jalons
précédents stabilisées. Les fichiers `MILESTONE_0N_*.md` de la racine restent la
référence fonctionnelle : en cas de contradiction, le brief prévaut et le plan
est corrigé.
