**Choix explicites (fiches 4.1) :**
- Distances classiques, circularité par topologie : même système `1000 + 5 × |Δp|` ; même galaxie `2700 + inter_system_distance × Δs` avec `Δs = min(|Δ|, S − |Δ|)` si `circular_systems` ; galaxies différentes `inter_galaxy_distance × Δg` (`Δg` circulaire si `circular_galaxies`) ; même position (planète ↔ lune ↔ débris) `5`.
- Vitesse d'une unité : `base_speed × (1 + niveau_moteur × bonus)` (`0,1` combustion, `0,2` impulsion, `0,3` hyperespace) ; surclassement de moteur (petit transporteur → impulsion à impulsion 5, vitesse 10000 ; bombardier → hyperespace à hyperespace-moteur 8, vitesse 5000 ; recycleur → impulsion à 17 (4000) puis hyperespace à 15 (6000)). Vitesse de flotte = minimum des unités. Pourcentage choisi `p ∈ {10, 20, …, 100}`.
- Durée aller : `seconds = floor((10 + 35000 / p × √(10 × distance / fleet_speed)) / universe_speed)` puis `max(minimum_mission_seconds)` ; `universe_speed` = `peaceful_fleet_speed` (transport, déploiement, espionnage, colonisation, recyclage), `hostile_fleet_speed` (attaque), `holding_fleet_speed` (stationnement M7). Retour = même durée.
- Carburant (aller-retour, prélevé sur la planète d'origine) : `fuel = 1 + floor(deuterium_consumption × Σ_i n_i × conso_i × distance / 35000 × (1 + p/100 × √(v_min / v_i))²)`.
- Capacité de cargo disponible = `Σ n_i × cargo_i − fuel` ; le cargo demandé ne peut dépasser cette valeur ni le stock.
- Slots de flotte : `research.Effects.FleetSlots()` ; flottes comptées = états `outbound`, `returning`, `recalled`.
- Missions M4 : `transport` (livraison du cargo, retour) et `deploy` (stationnement : la flotte et son cargo rejoignent définitivement une planète du même joueur, pas de retour). Livraison de transport plafonnée à la capacité de stockage cible ; l'excédent revient avec la flotte (règle explicite).
- Machine d'état persistée : `outbound → returning | completed | recalled | destroyed` ; `returning → completed` ; `recalled → completed` ; `completed`/`destroyed` terminaux. `prepared` n'existe qu'en mémoire (plan validé non persisté) ; `resolving` est le handler en cours de transaction. Rappel autorisé uniquement en `outbound` ; `returns_at = now + (now − departed_at)`.
- Événements : `fleet_arrived` (priorité 30, clé `fleet-arrive:<id>`) et `fleet_returned` (40, `fleet-return:<id>`). Le rappel annule l'événement d'arrivée (`state='cancelled'`, doit affecter exactement une ligne sinon `ErrConflict` : l'arrivée a gagné la course).
- Planète d'origine disparue au retour (M6+) : la flotte est marquée `destroyed` avec raison `origin_lost` (règle explicite, journalisée).

```go
	cases := []struct{ from, to string; want int64 }{
		{"1:1:8", "1:1:10", 1010}, {"1:1:8", "1:5:8", 3080}, {"1:100:8", "1:1:8", 2795}, {"1:1:8", "2:1:8", 20000}, {"3:1:8", "1:1:8", 20000}, {"1:1:8", "1:1:8", 5},
```

```go
func Distance(from, to universe.Coordinate, topology rules.TopologySettings) (int64, error) {
	limits := universe.Limits{Galaxies: topology.Galaxies, Systems: topology.SystemsPerGalaxy, Positions: topology.PositionsPerSystem}
	if err := from.Validate(limits); err != nil { return 0, err }
	if err := to.Validate(limits); err != nil { return 0, err }
	if from.Galaxy != to.Galaxy {
		delta := absInt(from.Galaxy - to.Galaxy)
		if topology.CircularGalaxies { delta = min(delta, topology.Galaxies-delta) }
		return int64(topology.InterGalaxyDistance) * int64(delta), nil
	}
	if from.System != to.System {
		delta := absInt(from.System - to.System)
		if topology.CircularSystems { delta = min(delta, topology.SystemsPerGalaxy-delta) }
		return 2700 + int64(topology.InterSystemDistance)*int64(delta), nil
	}
	if from.Position != to.Position {
		return 1000 + 5*int64(absInt(from.Position-to.Position)), nil
	}
	return 5, nil
}
```
