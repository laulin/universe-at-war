**Choix explicites (fiches 5.1) :**
- **Événements par mission** : une flotte `attack` planifie son arrivée comme `combat_resolved` (priorité 10), une flotte `espionage` comme `espionage_resolved` (20), les autres missions comme `fleet_arrived` (30). Les trois handlers appartiennent au `FleetRepository` et partagent `loadFleet`/`transitionFleet`. Clés : `fleet-arrive:<id>` pour les trois (une seule arrivée par flotte).
- **Espionnage** : `level = diff + isqrt(probes)` avec `diff = espionnage_attaquant − espionnage_défenseur` et `isqrt` la racine entière ; sections révélées si `level ≥` seuil (`resources_threshold` 1, `fleet_threshold` 2, `defenses_threshold` 3, `buildings_threshold` 4, `research_threshold` 5, seuils croissants validés). Une section révélée est complète et exacte (stock réglé à `due_at`) ; une section non révélée est absente du payload (pointeur nil), jamais partielle. Détection, tirée une fois avec la seed de la flotte : `p = clamp01(detection_base × probes × flotte_stationnée_défenseur × 2^(défenseur − attaquant))` (`detection_base` 0,0025, aucun tirage si `p = 0`) ; si détectée, toutes les sondes sont détruites (flotte `destroyed`, débris `ships_to_debris × coût payé des sondes`), le rapport attaquant est quand même produit avec `probes_lost`. Le défenseur reçoit **toujours** un rapport `espionage_detected` (nom et origine de l'attaquant, nombre de sondes, `probes_destroyed`), jamais le contenu révélé. Fraîcheur : `recent` si `now − occurred_at ≤ recent_report_seconds` (3600), sinon `old` ; section absente = `unknown`.
- **Combat** : unités individuelles (`{type, coque, bouclier_restant}`) disposées dans un ordre fixe : parties dans l'ordre du slice, types par identifiant croissant, instances par index ; le pool de cibles d'un round = unités vivantes au début du round. Statistiques par type calculées une fois avec `round_half_up` : `arme = floor(Weapon × (1 + 0,1 × armes) + 0,5)`, `bouclier_max = floor(Shield × (1 + 0,1 × bouclier) + 0,5)`, `coque_max = floor(Hull() × (1 + 0,1 × protection) + 0,5)`, `Hull() = (Metal + Crystal) / 10`. Round : boucliers restaurés ; attaquants puis défenseurs tirent (dégâts appliqués immédiatement, destructions différées en fin de round) ; tir : cible `IntN(len(pool))` (tirage omis si une seule cible), rebond si `dégâts × 100 < bouclier_max` (règle du 1 %), sinon bouclier puis coque ; rapid fire `rf > 1` → nouveau tir si `Float64() < (rf − 1)/rf`. Fin de round, attaquants puis défenseurs : `coque ≤ 0` → détruite sans tirage ; `coque × 100 < coque_max × 70` → survit ssi `Float64() < coque/coque_max` ; sinon survit sans tirage. Arrêt anticipé si un camp est vide ; issue `attacker` / `defender` / `draw` (rounds épuisés ou deux camps vides). Missiles exclus, défenses interdites côté attaquant, `MaximumUnitsPerSide = 10 000 000`. Constantes de moteur (`70`, `1 %`, `100 000`) dans `internal/domain/combat/constants.go` ; tunables dans `rules.CombatSettings`. **Une seule** source aléatoire consommée dans cet ordre, puis reconstruction des défenses (par type croissant, un tirage par unité détruite, `Float64() < defense_rebuild_chance`).
- **Débris** : `floor(ships_to_debris × Σ pertes vaisseaux × coût_payé)` + `floor(defenses_to_debris × Σ défenses détruites non reconstruites × coût_payé)` par ressource (métal, cristal ; jamais deutérium), avec `coût_payé = floor(BaseCost × multiplicateur de coût du ruleset)` passé dans `combat.Input.Multipliers`. Chance de lune `min(maximum_moon_chance, floor(débris_total / 100000) / 100)` (1 % par tranche de 100 000), journalisée, création au M6. Un champ à 0/0 n'existe pas (`CHECK (metal + crystal > 0)`, `DELETE` quand vidé) ; les champs sont publics dans la galaxie.
- **Pillage** (victoire attaquant, ≥ 1 survivant) : `ratio = min(economy.pillage_ratio, combat.maximum_pillage)` ; `avail_i = floor(stock_i × ratio)` ; `cap = Σ survivants × cargo − cargo déjà embarqué` ; passe 1 `loot_i = min(avail_i, cap/3)` ; passe 2 `free = cap − Σ loot`, métal `+= min(avail_m − loot_m, free/2)`, cristal `+= min(avail_c − loot_c, free/2)` ; passe 3 deutérium avec le reste ; passe 4 métal puis cristal avec le reste. Garantit `Σ loot = min(cap, Σ avail)`. Débit de la planète et chargement dans `fleet_cargo` dans la même transaction. Les technologies de l'attaquant sont celles **à l'arrivée** (classique, documenté).
- **Recyclage** : mission `recycle` vers `target_kind = 'debris'` (≥ 1 recycleur, champ non vide au lancement) ; à l'arrivée `capacité = min(recycleurs × recycler_capacity, cargo total − cargo embarqué)`, `cap = min(capacité, métal + cristal)`, `take = (min(métal, cap/2), min(cristal, cap/2))` puis reliquat sur métal puis cristal ; décrément guardé `UPDATE … WHERE metal >= ? AND crystal >= ?` ou `DELETE … WHERE metal = ? AND crystal = ?` (une ligne exactement, sinon erreur → nouvelle tentative) ; recycleurs concurrents ordonnés par `(due_at, priority, id)`, le second voit le reste ; champ disparu → prise 0.
- **Rapports** : table unique `reports` (D7) ; kinds `espionage`, `espionage_detected`, `combat_attack`, `combat_defense`, `recycling` ; payload versionné filtré à la création (`report.NewCombatPayloads`). Tout ce qu'un participant a pu observer pendant la bataille est visible des deux camps (compositions, pertes, technologies, rounds, débris, butin, chance de lune) ; `Rebuilt` est réservé au défenseur ; la seed et le stock restant de la planète ne figurent dans aucun payload. Rapports « hostiles » = `combat_defense` et `espionage_detected` (index partiel non lus).
- **Cible relue à l'arrivée** : la planète cible est recherchée par coordonnées (pas par `target_planet_id`), le propriétaire courant est le défenseur ; planète absente ou devenue propre → mission abandonnée, retour planifié, journal `mission_aborted`. Deux attaques dues au même instant sur la même planète se résolvent séquentiellement par `id`, la seconde contre l'inventaire post-bataille.
- **Galaxie (minimum M5)** : `GET /galaxy/{galaxy}/{system}` liste les positions (nom de planète, joueur, débris exacts) et propose « Espionner (N sondes) » (`POST /galaxy/{g}/{s}/{p}/spy`) et les liens « Attaquer » / « Recycler » pré-remplissant l'assistant d'envoi. Projection en lecture seule sans règlement ; jamais de ressources, bâtiments, unités ni flottes. L'indicateur d'activité est reporté au M8 (`players.last_active_at`, indispensable pour les IA).
- **Test double** : `random.NewScript(ints []int, floats []float64) Source` (panique si épuisé) pour les cas calculables à la main ; les goldens utilisent `NewSeeded`.
